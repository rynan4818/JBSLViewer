# デバッグ用仮スコア管理サーバ

`start.bat` を実行し、<http://127.0.0.1:18765/admin/> を開きます。Python 3.11以上。初回はこのフォルダの `.venv` へ依存関係をインストールします。APIは18082、Swaggerは <http://127.0.0.1:18082/docs>。実スコア管理の18081/18763と別のポートです。

このフォルダだけで起動できます。リーグ取得先が停止中でも管理画面と保存済み結果の閲覧は動作します。Ctrl+Cで仮スコアAPIと専用管理画面を終了します。

- 「サーバ挙動」でリーグ取得先（既定 `http://127.0.0.1:18080`）、認証用SID、障害と遅延、期限、時計差、キャッシュ、提出サイズ上限を設定します。
- 「提出スコア」「Challenge」で実際に届いた情報と状態・時刻・採用可否・メタデータ・リプレイ保存状態を確認します。
- 「消費回数」「受付履歴」で回数と、提出拒否を含む履歴を調べます。各一覧はページ切替と自動更新に対応します。
- `verify.bat` でPython試験を実行します。ゲームDLLは不要です。

`start.bat --api-port 19082 --admin-port 19765 --data-dir data_alt` で別の設定・DBを使えます。設定は `data/control.json`、受信データは `data/score.sqlite3` と `data/replays/` へ保存します。閲覧では期限切れ表示とDB状態を区別し、データを変更しません。

通常の起動バッチではstub認証を使います。実スコア管理の実装・設定・DBはこのフォルダから操作しません。各項目の「?」と図付きガイドでデバッグ条件を確認できます。

全体の接続・移行・自動検証は [../README.md](../README.md) を参照してください。

## 配布用ZIPの作成

`make_zip.bat` をダブルクリックするか、このフォルダで実行します。`dist/` に日時と識別子付きのZIPを新しく作成し、収録した全ファイルのSHA-256を検証します。既存のZIPは上書きしません。ZIP作成にはWindows標準のPowerShell/.NETだけを使います。

```bat
make_zip.bat
make_zip.bat -OutputDirectory "C:\temp\JBSL 配布"
```

現在の設定・DB・リプレイ・ログ・仮想環境・テスト・過去のZIPは含めません。配布先はZIPをフォルダごと展開し、同梱の `README.md` に従って `start.bat` を実行します。初回の依存パッケージ導入にはPythonとネット接続が必要です。

収録対象は [package-files.json](package-files.json) の明示的な一覧です。実行に必要なファイルを追加・改名した場合は、この一覧も更新してください。一覧外のファイルは、任意の名前で保存したデータも含めて収録しません。必要なファイルが欠けていれば作成を中止します。配布用READMEの原稿は [DISTRIBUTION.md](DISTRIBUTION.md) です。検証用コードとZIP作成ツール自体は、導入用ZIPには含めません。
